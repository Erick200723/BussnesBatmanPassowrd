# 🦇 Batsinal

Um app desenvolvido em **React Native com Expo** que simula o famoso **Bat Sinal**.  
O usuário pode ativar o sinal, preencher um formulário com seu **nome** e uma **mensagem**, e após o envio é exibido o **bat-logo** na tela.  

---

## 🚀 Tecnologias

- [React Native](https://reactnative.dev/)
- [Expo](https://expo.dev/)
- [TypeScript](https://www.typescriptlang.org/)

---

## 📂 Estrutura do Projeto

- **App.tsx** → Componente principal do aplicativo  
- **AppStyles.ts** → Estilos utilizados nos componentes  
- **/assets** → Contém imagens usadas no projeto (`batman.png`, `batLogo.png`)  

---

## 📜 Scripts Disponíveis

No diretório do projeto, você pode rodar:

- `npm start` → Inicia o servidor local (Metro Bundler)  
- `npm run android` → Executa o app em um emulador ou dispositivo Android  
- `npm run ios` → Executa o app em um emulador iOS  
- `npm run web` → Executa o app no navegador
